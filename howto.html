Cara Bikin

1) index.html (Struktur Halaman Website)

<!doctype html>
→ Memberi tahu browser bahwa ini adalah dokumen HTML5.

<html lang="en">
→ Membungkus seluruh isi website.
lang="en" menandakan bahasa utama kontennya Bahasa Inggris (baik untuk SEO & aksesibilitas).

Bagian <head>

<meta charset="utf-8" />
→ Supaya teks bisa menampilkan semua karakter dengan benar (termasuk simbol & emoji).

<meta name="viewport" content="width=device-width, initial-scale=1" />
→ Membuat website responsif di HP, tablet, dan laptop.

<title>Hongkong Book Club</title>
→ Judul yang muncul di tab browser.

<link rel="stylesheet" href="style.css" />
→ Menghubungkan file CSS agar HTML punya tampilan yang rapi.

Bagian <body>

<main class="card">
→ Elemen utama halaman.
class="card" dipakai supaya bisa di-style lewat CSS (tampil seperti kartu).

<h1>Hongkong Book Club</h1>
→ Judul utama website.

<p>Every Sunday • 9:00 AM</p>
<p>Victoria Park, Causeway Bay</p>
→ Informasi kegiatan (jadwal & lokasi).

<button id="joinBtn">Join & Register</button>
→ Tombol untuk daftar.
id="joinBtn" dipakai oleh JavaScript supaya tombol ini bisa diklik dan diberi aksi.

<small>Bring a book and come say hi ✨</small>
→ Teks kecil sebagai ajakan santai.

<script src="script.js"></script>
→ Menghubungkan file JavaScript agar tombol bisa membuka Google Form.
