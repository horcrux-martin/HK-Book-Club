Cara Bikin

1) index.html (Struktur Halaman Website)

<!doctype html>
→ Memberi tahu browser bahwa ini adalah dokumen HTML5.

<html lang="en">
→ Membungkus seluruh isi website.
lang="en" menandakan bahasa utama kontennya Bahasa Inggris (baik untuk SEO & aksesibilitas).

Bagian <head>

<meta charset="utf-8" />
→ Supaya teks bisa menampilkan semua karakter dengan benar (termasuk simbol & emoji).

<meta name="viewport" content="width=device-width, initial-scale=1" />
→ Membuat website responsif di HP, tablet, dan laptop.

<title>Hongkong Book Club</title>
→ Judul yang muncul di tab browser.

<link rel="stylesheet" href="style.css" />
→ Menghubungkan file CSS agar HTML punya tampilan yang rapi.

Bagian <body>

<main class="card">
→ Elemen utama halaman.
class="card" dipakai supaya bisa di-style lewat CSS (tampil seperti kartu).

<h1>Hongkong Book Club</h1>
→ Judul utama website.

<p>Every Sunday • 9:00 AM</p>
<p>Victoria Park, Causeway Bay</p>
→ Informasi kegiatan (jadwal & lokasi).

<button id="joinBtn">Join & Register</button>
→ Tombol untuk daftar.
id="joinBtn" dipakai oleh JavaScript supaya tombol ini bisa diklik dan diberi aksi.

<small>Bring a book and come say hi ✨</small>
→ Teks kecil sebagai ajakan santai.

<script src="script.js"></script>
→ Menghubungkan file JavaScript agar tombol bisa membuka Google Form.

2) style.css (Tampilan / Desain)

Kenapa Style CSS dibuat seperti ini?

Style CSS ini dibuat dengan tujuan sederhana, ringan, dan mudah dipahami oleh pemula.

  • Tanpa framework (seperti Bootstrap atau Tailwind) supaya fokus ke dasar CSS.
  • display: grid + place-items: center dipakai agar konten selalu berada di tengah layar tanpa perlu hitung margin atau posisi manual.
  • .card digunakan supaya tampilan terlihat seperti kartu modern: ada padding, sudut membulat, dan bayangan.
  • max-width + width: 90% membuat tampilan tetap rapi di HP maupun desktop.
  • button styling dibuat jelas dan kontras agar fokus utama pengguna adalah tombol daftar.

3) script.js (Fungsi Tombol)

Kenapa Script JavaScript dibuat seperti ini?

JavaScript di website ini dibuat sesingkat dan sejelas mungkin, karena tujuannya hanya satu: membuka link Google Form saat tombol diklik.

  • document.getElementById("joinBtn") digunakan karena hanya ada satu tombol yang perlu dikontrol.
  • onclick dipakai supaya pemula bisa langsung paham konsep event klik.
  • window.open() digunakan agar Google Form terbuka di tab baru, sehingga halaman utama tidak tertutup.
  • "_blank" memastikan pengguna tetap bisa kembali ke website setelah daftar.

Dengan cara ini, JavaScript tetap ringan, tidak berlebihan, dan mudah dimodifikasi jika nanti ingin menambah fitur lain.
